# Hyrule Cheat Menu v1.2.1

Restores the **Ctrl+U** High Refresh toggle in Fritchii v6.1. Hyrule Cheat Menu v1.2.0 placed hook bridges in executable padding that Fritchii also uses for its frame-rate patches. This release moves the bridges and preserves the menu layout and features.

Close the game and extract **`Hyrule-Cheat-Menu-v1.2.1.zip`**, replacing the complete mod folder so both ExeFS files are updated. Remove any duplicate enabled copy of the older add-on. The source ZIP is for building and review.

Validated on Windows Fritchii v6.1 with displayed game update 2.0.0 and main Build ID `E0F3CCFAF50065AE4EA01EB5AEB13B1A45DA3348`.
