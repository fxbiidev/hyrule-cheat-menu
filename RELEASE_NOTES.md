# Hyrule Cheat Menu v1.2.0

Open the **Cheats** tab, expand **World Cheats** and enable **Increased Luck**. Each eligible ordinary grass cut yields one pickup. Green Rupees (1 Rupee) drop 85% of the time and blue Rupees (5 Rupees) drop 15% of the time.

Pickups use the game's normal wallet capacity and work with Infinite Rupees. Special grass drops keep their stock behavior. Turn the toggle off to restore stock odds immediately. Loading a save resets the toggle to OFF.

Install **`Hyrule-Cheat-Menu-v1.2.0.zip`** by replacing the complete mod folder while the game is closed. The optional source ZIP is for building and review. The supported target is Windows Lichii Build 177, displayed update 2.0.0, main Build ID `E0F3CCFAF50065AE4EA01EB5AEB13B1A45DA3348`.
